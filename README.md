# 七步五项法

**Seven-Step Five-Item Method**

一套用于**信息不完全、认知能力有限、判断困难或希望降低临场思考负担**时的问题处理程序。

它不保证一次得到正确答案，也不要求使用者首先知道根因。其核心目的，是将当前问题逐步转换为：

> **更接近目标、更容易判断、更容易继续处理，或更容易升级移交的状态。**

## 七步主流程

1. **定界**：我要什么？我愿意拿什么换？
2. **原始样本**：未经解释，实际发生了什么？
3. **分类**：从状态、条件、资源、约束、轨迹五个角度整理问题。
4. **归因**：生成候选原因，寻找关键分叉与区分判据。
5. **下一动作**：从结果、成本、风险、信息、余地五项评价候选动作。
6. **反馈**：记录实际操作、实际输出以及判断如何改变。
7. **退出 / 升级**：继续、等待、换路、停止，或将加工后的问题升级移交。

## 问题五项

**状态｜条件｜资源｜约束｜轨迹**

- **状态**：现在是什么样？
- **条件**：在什么情况下发生、消失、增强、减弱或改变？
- **资源**：现在有什么可以被调用？
- **约束**：什么边界不能越过？
- **轨迹**：它是怎么走到现在的？

## 动作五项

**结果｜成本｜风险｜信息｜余地**

- **结果**：这一动作能够把目标推进多少？
- **成本**：为了执行这一动作，我预计并主动接受付出什么？
- **风险**：除了预计成本之外，还可能额外发生什么不希望发生的损失？
- **信息**：这一动作能否提高后续判断能力？
- **余地**：执行以后仍保有多少未来行动空间？

其中：

- **信息三项**：增减量｜可信度｜解释性
- **余地四项**：恢复｜重试｜换路｜裕度

## 有效行动判据

一次行动至少应使问题在以下方向之一有所改善：

- 更接近目标；
- 获得更好的判断信息；
- 缩小或改善候选原因结构；
- 提高后续处理能力；
- 提高问题的可描述、可判断或可移交程度。

如果一次行动既不推进结果，也不改善信息、判断、未来行动空间或交接质量，却持续消耗成本，则属于高度可疑的**纯损耗行动**。
