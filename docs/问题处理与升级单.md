# 七步五项法 · 问题处理与升级单

> 不知道就写“**不知道**”，没有就写“**无**”，不适用就写“**不适用**”。
>
> **事实与猜测必须分开。**

---

# ① 定界

| 问题 | 填写 |
|---|---|
| **你最后想得到什么结果？** |  |
| **为了得到这个结果，你愿意花多少时间？** |  |
| **愿意花多少钱？** |  |
| **愿意承受哪些麻烦、不便或损失？** |  |
| **有没有明确不愿意付出的代价？** |  |

---

# ② 原始样本

**这里只写实际观察到、测到、读取到或明确发生的内容，不写“我觉得是因为……”**

| 问题 | 填写 |
|---|---|
| **你做了什么以后发现问题？** |  |
| **系统、设备或事情实际出现了什么结果？** |  |
| **有没有错误提示、数字、记录、截图、声音或其他异常现象？请原样记录。** |  |
| **哪些事情是你可以确定发生过的？** |  |

---

# ③ 问题画像

| 项目 | 核心问题 | 填写 |
|---|---|---|
| **状态** | **现在到底是什么样？** |  |
| **条件** | **什么时候会发生？什么时候不会？什么情况下更严重或更轻？** |  |
| **资源** | **现在有什么可以拿来处理问题？钱、时间、工具、权限、人员、设备等都算。** |  |
| **约束** | **有什么绝对不能做、不能超过或不能破坏？** |  |
| **轨迹** | **以前怎样？中间发生了什么变化？后来又怎样？** |  |

> 同一事实可以出现在多个栏目，只要它在不同栏目具有不同意义。

---

# ④ 归因

这里允许提出猜测，但必须和事实分开。

| 问题 | 填写 |
|---|---|
| **现在能想到哪些可能原因？** | 1.  \n2.  \n3.  |
| **哪些原因如果成立，会导致不同的处理办法？** |  |
| **现在最需要先区分的是哪几个原因？** |  |
| **看什么现象、查什么信息、做什么测试，可以把它们区分开？** |  |

如果想不到原因，直接写：**不知道**。

---

# ⑤ 下一动作

**我下一步准备做：** ____________________________________________

| 项目 | 核心问题 | 填写 |
|---|---|---|
| **结果** | **做完这一步，能让我离目标近多少？** |  |
| **成本** | **这一步确定要花掉什么？时间、钱、精力等。** |  |
| **风险** | **除了预计成本，还可能额外搞坏、搞丢或造成什么损失？** |  |
| **信息** | **即使没解决问题，这一步能让我知道什么之前不知道的有用东西？** |  |
| **余地** | **如果失败，还能不能恢复、重试、换路？还剩多少时间、钱、机会或安全空间？** |  |

## 信息补充

| 项目 | 判断 |
|---|---|
| **增减量** | ☐ 变多　☐ 没变　☐ 变少 |
| **可信度** | ☐ 高　☐ 中　☐ 低　☐ 不知道 |
| **解释性** | ☐ 更清楚　☐ 没变化　☐ 更乱 |

## 余地补充

| 项目 | 问题 | 填写 |
|---|---|---|
| **恢复** | **走错以后还能恢复吗？** |  |
| **重试** | **还能再试吗？大概还能试几次？** |  |
| **换路** | **这条路不行，还有别的方法吗？** |  |
| **裕度** | **做完以后还剩多少时间、钱、安全空间或其他资源？** |  |

# ⑥ 反馈

**这一部分应在实际操作后填写。**

| 问题 | 填写 |
|---|---|
| **你实际上做了什么？** |  |
| **实际出现了什么结果？** |  |
| **和原来预计的一样吗？** | ☐ 一样　☐ 部分一样　☐ 不一样 |
| **哪些原来的原因现在更可能了？** |  |
| **哪些原因现在不太可能或已经可以排除了？** |  |
| **有没有出现新的可能原因？** |  |
| **下一步因此需要改变吗？** |  |

新的结果可以作为下一轮的**新原始样本**。

---

# ⑦ 退出 / 升级

请选择当前状态：

| 选择 | 含义 | 勾选 |
|---|---|---|
| **继续** | 当前路线还有价值，进入下一轮 | ☐ |
| **等待** | 缺少信息、时间、资源或条件，等待变化 | ☐ |
| **换路** | 目标不变，但当前办法不值得继续 | ☐ |
| **停止** | 目标已完成，或继续处理已经不值得 | ☐ |
| **升级求助** | 已到达自己的能力、权限、工具或风险边界 | ☐ |

| 问题 | 填写 |

| **我现在具体卡在哪一步？** |  |

| **我希望对方具体帮我什么？** |  |
| **我已经做过哪些尝试？** |  |
| **每次尝试分别得到了什么结果？** |  |
| **有哪些东西绝对不能动？** |  |

## 最终求助摘要

> **我要达到 ______。现在确认 ______。已经试过 ______，结果是 ______。目前主要怀疑 ______。但因为 ______，我卡在这里。我需要你帮我 ______。约束是 ______。**
